## 설치 방법

1. 작업에 쓰는 Windows 계정을 **표준 사용자**로 바꿉니다(설정 → 계정 → 가족 및 기타 사용자 → 계정 유형 변경).
2. **`DigitalWellbeing-Setup-….exe`**를 내려받아 실행합니다. 관리자 비밀번호를 묻습니다.
3. 설치 중 "Work account" 화면에 작업 계정의 사용자 이름을 적습니다. 비워 두면 관리자 계정까지 모든 계정이 관리됩니다.
4. 설치가 끝나면 작업 계정으로 로그인합니다. 로그인하면 **Digital Wellbeing Focus** 창(Focus 앱)이 뜹니다. 창이 보이지 않으면 시작 메뉴의 **Digital Wellbeing Focus**나 트레이의 Focus 아이콘으로 엽니다.
5. 설치 직후에는 설정이 잠겨 있지 않습니다. Focus 앱의 **Settings** 탭에서 **Open the settings**를 누르고, **AI focus** 화면에 Anthropic API 키를 저장합니다. 블랙리스트, 할 일 플래너 같은 다른 설정도 이 탭에서 정합니다.
6. 설정을 다 정했으면 같은 Settings 탭에서 설정을 잠급니다(아래 "바로 잠그세요").

설치 프로그램 없이 쓰려면 `…-windows-x64.zip`을 풀고 `install.cmd`를 실행합니다.
자세한 설명은 설치 폴더의 `docs\multi_account.md`에 있습니다.

**설치하거나 업데이트한 뒤 바로 설정을 잠그세요.** 설정이 잠겨 있지 않으면 이 PC의 누구든 Focus 앱의 Settings 탭으로 모든 설정을 고칠 수 있습니다.
작업 계정의 Focus 앱에서 Settings 탭을 열고 기간(1시간~366일)을 정해 **Lock**을 누르세요. 잠금은 늘릴 수만 있고, 프로그램 안의 어떤 화면도 잠금을 일찍 풀지 못합니다. 처음에는 짧게 잠가서 설정이 원하는 대로 동작하는지 확인하세요.

## 이번 버전에서 바뀐 것 (rc.4 이후)

- **"Work account" 칸을 비우면 모든 계정을 관리합니다.** 설치 프로그램은 칸이 비어 있으면 관리자 계정을 포함한 모든 계정을 관리하라고 서비스에 알립니다(`install --manage-all`). 예전에는 업데이트할 때 칸을 비워 두면 이전에 정한 계정 목록이 그대로 남았습니다.
- 관리할 계정을 여러 개 정하려면 관리자 PowerShell에서 `digital-wellbeing-service.exe install --manage <계정1> --manage <계정2>`를 실행합니다. 서비스는 2초마다 이 목록을 다시 읽으므로, 이미 로그인해 있는 계정에도 몇 초 안에 agent가 뜹니다.
- Focus 앱에 "agent not running for this session"이 나오면, 그 계정이 관리 대상이 아니라는 뜻일 가능성이 높습니다. 위 방법으로 그 계정을 관리 대상에 넣으세요.

## rc.3 이후 바뀐 것 (rc.4에 들어 있던 것)

- **관리자용 설정 창이 없어졌습니다.** 설치 프로그램은 `digital-wellbeing.exe`와 시작 메뉴의 "Digital Wellbeing settings (admin)"를 더 이상 설치하지 않고, 업데이트할 때 예전 버전이 남긴 `digital-wellbeing.exe`를 지웁니다. 릴리스 zip에도 이 파일이 없습니다.
  모든 설정(블랙리스트, AI focus 설정과 API 키, 차단 풀기, 접근 허용 취소, AI 사용량과 하루 예산, 할 일 플래너와 생활 규칙)은 작업 계정의 Focus 앱 **Settings** 탭에서 고칩니다.
  프로그램은 관리자 계정과 표준 계정을 구별하지 않고, 설정 잠금만 보고 설정을 고칠 수 있는지 정합니다. 잠금을 일찍 푸는 기능은 없습니다.
  관리자 계정은 설치할 때와 관리할 계정을 바꿀 때(`install --manage`)만 씁니다.
- **열린 창을 모두 판정합니다.** 맨 앞 창(화면 캡처 포함)과 함께, 다른 브라우저 창의 탭 제목과 다른 프로그램의 이름·창 제목도 AI에게 보냅니다. 뒤쪽 창의 딴짓 탭은 바로 차단되고, 그 창이 화면에 보이면 포커스를 빼앗지 않고 최소화됩니다. 탭은 그 창을 앞으로 가져올 때 닫힙니다. 뒤쪽 프로그램은 앞에 있는 앱과 같은 규칙으로 경고를 쌓고 꺼집니다.
- **새 앱이나 사이트는 바로 판정합니다.** 지금 할 일에 대한 판정 기록이 없는 창이 보이면, 모니터는 3초마다 하는 확인에서 기다리지 않고 바로 AI에게 맡깁니다. 무작위 정기 검사와 "10초 머문 창부터 먼저 검사" 규칙은 없어졌습니다.
- **판정마다 다시 검사할 시각이 있습니다.** 할 일에 필요하다고 판정된 창은 15분 뒤에, 애매하다고 판정된 창이나 경고를 쌓는 중인 앱은 60초 뒤에 다시 판정합니다. 두 시간은 Settings 탭에서 바꿀 수 있습니다. API 호출이 실패하면 60초 동안 다시 시도하지 않습니다.

## rc.2 이후 바뀐 것 (rc.3에 들어 있던 것)

- **YouTube는 채널 단위로 차단합니다.** AI가 화면에서 채널 이름을 읽고, 딴짓 채널만 막습니다.
- **탭은 첫 `off_task` 판정에서 바로 닫힙니다.** 앱은 지금처럼 경고 횟수를 채운 뒤에 끕니다.
- **차단은 시간이 지나도 풀리지 않습니다.** 접근 요청이 승인되거나, 설정이 잠겨 있지 않을 때 사용자가 Settings 탭에서 풀 때만 풀립니다. Settings 탭의 AI focus 화면에 사용자별 차단 목록과 unblock 버튼이 생겼습니다.
- **생활 규칙:** Settings 탭의 Task planner 화면에 적은 규칙을 할 일 추천, 변경 심사, 제안 심사가 모두 따릅니다.
- **할 일 제안:** Focus 앱이나 Claude Desktop에서 할 일을 제안하면, AI가 생활 규칙으로 심사해서 승인한 것만 목록에 넣습니다.
- **Claude Desktop 연결:** `digital-wellbeing-mcp.exe`를 Claude Desktop에 등록하면 Claude가 할 일을 보고, 제안하고, 변경을 요청할 수 있습니다. 차단을 풀거나 규칙을 바꾸는 도구는 없습니다. 설정 방법은 `docs\claude_desktop.md`에 있습니다.
- **설정 잠금:** 위의 "바로 잠그세요"를 보세요. 자세한 설명은 `docs\multi_account.md` 6.4절에 있습니다.
- **트레이 아이콘:** Focus 창을 닫으면 트레이로 숨습니다. 아이콘을 누르면 다시 열리고, 메뉴에서 Settings를 열거나 앱을 끝낼 수 있습니다.
- **토큰 사용량:** Settings 탭의 AI focus 화면에 오늘과 이번 달의 호출 수, 토큰 수, 예상 비용이 나옵니다. 하루 예산을 정하면 예산을 다 쓴 날에는 창 검사를 멈춥니다.

## 주의

- **시험판입니다.** 이 버전은 GitHub Actions의 Windows에서 빌드와 자동 테스트만 거쳤고, 실제 PC에서 서비스·화면 캡처·탭 닫기를 확인하지 않았습니다. 처음 설치한 뒤 `docs\multi_account.md` 5장의 점검 목록을 따라 해 보세요.
- **서명되지 않은 실행 파일입니다.** Windows SmartScreen이 "알 수 없는 게시자" 경고를 띄웁니다. "추가 정보 → 실행"을 눌러야 합니다.
- 제거는 Windows 설정의 **앱 → 설치된 앱**에서 합니다. 설정 폴더 `C:\ProgramData\DigitalWellbeing`은 남으므로, 필요하면 직접 지웁니다.
