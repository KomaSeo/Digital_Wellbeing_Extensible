## 설치 방법

1. 작업에 쓰는 Windows 계정을 **표준 사용자**로 바꿉니다(설정 → 계정 → 가족 및 기타 사용자 → 계정 유형 변경).
2. **`DigitalWellbeing-Setup-….exe`**를 내려받아 실행합니다. 관리자 비밀번호를 묻습니다.
3. 설치 프로그램은 계정을 묻지 않습니다. 관리자 계정을 포함한 이 PC의 모든 계정이 관리됩니다.
4. 설치가 끝나면 작업 계정으로 로그인합니다. 로그인하면 **Digital Wellbeing Focus** 창(Focus 앱)이 뜹니다. 창이 보이지 않으면 시작 메뉴의 **Digital Wellbeing Focus**나 트레이의 Focus 아이콘으로 엽니다.
5. 설치 직후는 **설정 단계**입니다. 설정 단계는 엄격 모드(아래)를 켜기 전의 상태이고, 설정 단계에서는 적용한 설정이 바로 효력을 가집니다. Focus 앱의 **설정** 탭을 열고, **AI 연결** 영역에 Anthropic API 키를 붙여 넣고 **이 키 쓰기**를 누른 뒤, 그 아래의 **적용**을 누릅니다. 항상 막을 프로그램과 웹사이트, 생활 규칙 같은 다른 설정도 이 탭에서 정합니다. 설정마다 아래에 **적용** 버튼이 있습니다. 할 일 목록은 **할 일** 탭에서 만듭니다.
6. 설정을 다 정했으면 같은 설정 탭 맨 위에서 엄격 모드를 켭니다(아래 "엄격 모드를 켜세요").
7. (권장) 관리자 계정에서 우회를 막는 추가 설정을 합니다. 관리자 계정 비밀번호를 쉽게 꺼낼 수 없는 곳에 두고, BIOS(UEFI)에 관리자 비밀번호를 걸고 USB 부팅을 끄고, 안전 모드로 들어가는 길(Windows 복구 환경)을 끕니다. 방법은 `docs\multi_account.md` 4.4절에 있습니다.

설치 프로그램 없이 쓰려면 `…-windows-x64.zip`을 풀고 `install.cmd`를 실행합니다.
자세한 설명은 설치 폴더의 `docs\multi_account.md`에 있습니다.

**설치한 뒤 설정을 마쳤으면 엄격 모드를 켜세요.** **엄격 모드**는 설정을 잠그는 상태이고, 예전 버전에서는 **설정 보호**라고 불렀습니다. 설정 단계에서는 이 PC의 누구든 Focus 앱의 설정 탭으로 모든 설정을 바로 고칠 수 있습니다.
작업 계정의 Focus 앱에서 설정 탭을 열고, 맨 위의 **엄격 모드** 영역에서 엄격 모드를 끄는 방법을 고르고, "고른 방법이 아니면 엄격 모드를 끌 수 없다는 것을 이해했습니다."를 체크한 뒤 **엄격 모드 켜기**를 누르세요.
엄격 모드를 켠 뒤에는 규칙을 더 엄격하게 만드는 변경(**엄격한 변경**, 예: 항상 막을 프로그램이나 웹사이트 넣기, 앱을 끄기까지의 판정 수 줄이기, 접근 허용 취소)만 바로 적용됩니다. 그 밖의 변경(**느슨한 변경**, 예: 차단 풀기, 생활 규칙이나 API 키 바꾸기)은 바로 적용되지 않고 **예약된 업데이트**가 됩니다. 예약하고 정해진 시간(**질문 간격**, 기본값은 이틀)이 지나면 Focus 앱이 "이 업데이트가 정말 맞나요?"라고 묻고(**확인 질문**), 사용자가 질문 간격마다 정해진 횟수(**확인 횟수**, 기본값은 세 번)만큼 연속으로 "예"라고 답해야 그 업데이트가 적용됩니다. 한 번이라도 "아니요"라고 답하면 거절됩니다.
엄격 모드를 끄는 방법은 **기간**(정한 시각 전에는 끌 수 없음), **영구**(끌 수 없음), **관리자 권한**(Windows의 관리자 승인 창에서 승인해야 꺼짐), **비밀번호**(정한 비밀번호를 넣어야 꺼짐) 중에서 고릅니다. 엄격 모드를 끄면 설정 단계로 돌아가고 걸린 차단도 모두 풀립니다. 엄격 모드를 켜기 전에 며칠 써 보며 설정이 원하는 대로 동작하는지 확인하세요.
설정 잠금이 있던 예전 버전(rc.9까지)에서 업데이트했고 설정을 잠근 적이 있다면, 엄격 모드가 이미 켜진 것으로 봅니다.

## 이번 버전에서 바뀐 것

이 절에서 **엄격 모드**는 예전에 "설정 보호"라고 부르던 것입니다. 엄격 모드를 켜면 규칙을 느슨하게 만드는 변경은 바로 적용되지 않고 확인 질문을 거칩니다.

- **"설정 보호"의 이름이 "엄격 모드"로 바뀌었습니다.** 하는 일은 같습니다. 엄격 모드는 이제 설정 탭 맨 위가 아니라, AI 연결, AI 규칙, 차단, AI 검사, 시스템 옆의 **엄격 모드** 탭에 있습니다.
- **일하기 탭이 생겼습니다.** 할 일 탭 왼쪽의 일하기 탭에서 지금 할 일, 할 일 받기, 끝냈다·연장하기·다른 일 받기, 사용 중지를 합니다. 할 일 탭에서는 할 일 목록과 약속을 관리합니다. Focus 앱을 열면 일하기 탭이 먼저 보입니다.
- **할 일을 받을 때 지금 상황을 적을 수 있습니다.** 일하기 탭의 "할 일 받기" 위에 "지금 상황" 칸이 있습니다. 예를 들어 "카페에서 노트북만 있음, 1시간 뒤 약속"처럼 적으면, AI가 그 상황에서 할 수 있는 할 일을 고릅니다. 적은 상황은 바꿀 때까지 남습니다.
- **엄격 모드가 꺼져 있으면 AI가 심사하지 않습니다.** 할 일 추가, 고치기, 지우기, 완료 보고("끝냈다")가 바로 적용됩니다. 이유를 적지 않아도 됩니다. 추가한 할 일은 적은 칸과 기본값(중요도 3)으로 들어갑니다. 약속 추가와 그 밖의 변경 요청은 지금처럼 AI가 정합니다.
- **엄격 모드가 꺼져 있으면 사용 중지는 앱과 웹사이트를 막지 않습니다.** 지금 할 일은 끝나고 AI 검사는 멈춥니다. 엄격 모드가 켜져 있으면 지금처럼 모든 앱과 웹사이트가 잠깁니다.
- **완료 보고의 보내기 버튼을 고쳤습니다.** 예전에는 처음 열었을 때와 다른 종류를 골랐다 돌아왔을 때 버튼이 다르게 켜졌습니다. 이제 "끝낸 것" 칸에 4글자 이상 적으면 켜지고, 꺼져 있으면 그 이유가 버튼 아래에 나옵니다. "증거" 칸은 선택입니다.
- **같은 컴퓨터는 다시 설치해도 같은 기기로 붙습니다.** 예전에는 사용자 정보를 지우고 다시 설치하면, 동기화 서버의 기기 목록에 같은 컴퓨터가 두 번 나왔습니다. 설정 탭 → 기기 동기화 → **서버에 붙은 기기**에서 기기마다 버전과 마지막 동기화 시각을 볼 수 있고, 예전에 생긴 중복 줄이나 더는 쓰지 않는 컴퓨터는 **목록에서 지우기**로 지웁니다. 최근 10분 안에 동기화한 기기는 지워지지 않습니다.

## 주의

- **시험판입니다.** 이 버전은 GitHub Actions의 Windows에서 빌드와 자동 테스트만 거쳤고, 실제 PC에서 서비스·화면 캡처·탭 닫기를 확인하지 않았습니다. 처음 설치한 뒤 `docs\multi_account.md` 5장의 점검 목록을 따라 해 보세요.
- **서명되지 않은 실행 파일입니다.** Windows SmartScreen이 "알 수 없는 게시자" 경고를 띄웁니다. "추가 정보 → 실행"을 눌러야 합니다.
- 제거는 Windows 설정의 **앱 → 설치된 앱**에서 합니다. 제거 프로그램의 창에서 사용자 정보(설정 폴더 `C:\ProgramData\DigitalWellbeing`)도 지울지(처음에 체크 해제)와 안전 모드를 다시 열지(처음에 체크)를 고릅니다.
