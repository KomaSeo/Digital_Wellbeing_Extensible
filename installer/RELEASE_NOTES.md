## 설치 방법

1. 작업에 쓰는 Windows 계정을 **표준 사용자**로 바꿉니다(설정 → 계정 → 가족 및 기타 사용자 → 계정 유형 변경).
2. **`DigitalWellbeing-Setup-….exe`**를 내려받아 실행합니다. 관리자 비밀번호를 묻습니다.
3. 설치 프로그램은 계정을 묻지 않습니다. 관리자 계정을 포함한 이 PC의 모든 계정이 관리됩니다.
4. 설치가 끝나면 작업 계정으로 로그인합니다. 로그인하면 **Digital Wellbeing Focus** 창(Focus 앱)이 뜹니다. 창이 보이지 않으면 시작 메뉴의 **Digital Wellbeing Focus**나 트레이의 Focus 아이콘으로 엽니다.
5. 설치 직후는 **설정 단계**입니다. 설정 단계에서는 적용한 설정이 바로 효력을 가집니다. Focus 앱의 **설정** 탭을 열고, **AI 연결** 영역에 Anthropic API 키를 붙여 넣고 **이 키 쓰기**를 누른 뒤, 그 아래의 **적용**을 누릅니다. 항상 막을 프로그램과 웹사이트, 생활 규칙 같은 다른 설정도 이 탭에서 정합니다. 설정마다 아래에 **적용** 버튼이 있습니다. 할 일 목록은 **할 일** 탭에서 만듭니다.
6. 설정을 다 정했으면 같은 설정 탭 맨 위에서 설정을 보호합니다(아래 "설정을 보호하세요").
7. (권장) 관리자 계정에서 우회를 막는 추가 설정을 합니다. 관리자 계정 비밀번호를 쉽게 꺼낼 수 없는 곳에 두고, BIOS(UEFI)에 관리자 비밀번호를 걸고 USB 부팅을 끄고, 안전 모드로 들어가는 길(Windows 복구 환경)을 끕니다. 방법은 `docs\multi_account.md` 4.4절에 있습니다.

설치 프로그램 없이 쓰려면 `…-windows-x64.zip`을 풀고 `install.cmd`를 실행합니다.
자세한 설명은 설치 폴더의 `docs\multi_account.md`에 있습니다.

**설치한 뒤 설정을 마쳤으면 설정을 보호하세요.** 설정 단계에서는 이 PC의 누구든 Focus 앱의 설정 탭으로 모든 설정을 바로 고칠 수 있습니다.
작업 계정의 Focus 앱에서 설정 탭을 열고, 맨 위의 **설정 보호(잠금)** 영역에서 보호를 푸는 방법을 고르고, "고른 방법이 아니면 보호를 풀 수 없다는 것을 이해했습니다."를 체크한 뒤 **설정 보호하기**를 누르세요.
설정을 보호한 뒤에는 규칙을 더 엄격하게 만드는 변경(**엄격한 변경**, 예: 항상 막을 프로그램이나 웹사이트 넣기, 앱을 끄기까지의 판정 수 줄이기, 접근 허용 취소)만 바로 적용됩니다. 그 밖의 변경(**느슨한 변경**, 예: 차단 풀기, 생활 규칙이나 API 키 바꾸기)은 바로 적용되지 않고 **예약된 업데이트**가 됩니다. 예약하고 정해진 시간(**질문 간격**, 기본값은 이틀)이 지나면 Focus 앱이 "이 업데이트가 정말 맞나요?"라고 묻고(**확인 질문**), 사용자가 질문 간격마다 정해진 횟수(**확인 횟수**, 기본값은 세 번)만큼 연속으로 "예"라고 답해야 그 업데이트가 적용됩니다. 한 번이라도 "아니요"라고 답하면 거절됩니다.
보호를 푸는 방법은 **기간**(정한 시각 전에는 풀 수 없음), **영구**(풀 수 없음), **관리자 권한**(Windows의 관리자 승인 창에서 승인해야 풀림), **비밀번호**(정한 비밀번호를 넣어야 풀림) 중에서 고릅니다. 보호를 풀면 설정 단계로 돌아가고 걸린 차단도 모두 풀립니다. 보호하기 전에 며칠 써 보며 설정이 원하는 대로 동작하는지 확인하세요.
설정 잠금이 있던 예전 버전(rc.9까지)에서 업데이트했고 설정을 잠근 적이 있다면, 설정은 이미 보호된 것으로 봅니다.

## 이번 버전에서 바뀐 것

이 절에서 **프롬프트 캐시**는 질문의 앞부분이 바로 전 질문과 똑같을 때 Anthropic 서버가 그 앞부분을 기억해 두었다가 싸게 다시 쓰는 기능을 말합니다.

- **할 일 고르기와 각종 심사의 비용이 줄어듭니다.** 이 질문들은 물을 때마다 남은 할 일 목록 전체를 보내는데, 이제 목록을 질문 맨 앞에 두고 프롬프트 캐시를 씁니다. 같은 종류의 질문이 한 시간 안에 다시 오면, 목록 부분을 원래 입력 가격의 20분의 1로 읽습니다. 할 일을 고친 직후의 첫 질문만 목록을 새로 기억시키느라 목록 부분에 2배를 냅니다. 보내는 내용은 같으므로 AI의 판단은 달라지지 않습니다.
- **모델 비교를 시작합니다.** 창 검사, 변경 요청 심사, 할 일 고르기, 할 일 변경 심사, AI 비서의 질문 중 10%를 Opus, Sonnet, Haiku에게 똑같이 물어 답을 비교합니다. 비교하는 답은 아무것도 바꾸지 않습니다. 결과는 통계 탭의 **모델 비교**에 나옵니다. 기능마다 싼 모델이 Opus와 같은 답을 한 비율("같음")과 더 느슨하게 답한 비율("위험": 딴짓을 놓치거나 거절할 요청을 승인함)이 나오고, 답이 달랐던 질문을 직접 읽을 수 있습니다. 싼 모델로 바꿔도 되는지 판단하는 데 씁니다.
  - 비교 기록은 AI 사용량과 함께 동기화 서버에 저장되므로, 여러 PC의 기록이 합쳐집니다. 화면 캡처와 API 키는 서버로 가지 않습니다.
  - 비교에 드는 비용은 AI 사용량에 "모델 비교"로 따로 나옵니다. 하루 $1~1.5 정도로 예상합니다.
  - 비율은 설정 탭 → AI 연결 → AI 하루 예산 아래의 "모델 비교" 칸에서 바꾸고, 0으로 하면 끕니다.

## 주의

- **시험판입니다.** 이 버전은 GitHub Actions의 Windows에서 빌드와 자동 테스트만 거쳤고, 실제 PC에서 서비스·화면 캡처·탭 닫기를 확인하지 않았습니다. 처음 설치한 뒤 `docs\multi_account.md` 5장의 점검 목록을 따라 해 보세요.
- **서명되지 않은 실행 파일입니다.** Windows SmartScreen이 "알 수 없는 게시자" 경고를 띄웁니다. "추가 정보 → 실행"을 눌러야 합니다.
- 제거는 Windows 설정의 **앱 → 설치된 앱**에서 합니다. 제거 프로그램의 창에서 사용자 정보(설정 폴더 `C:\ProgramData\DigitalWellbeing`)도 지울지(처음에 체크 해제)와 안전 모드를 다시 열지(처음에 체크)를 고릅니다.
